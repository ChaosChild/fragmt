# OKF rung 5: graph view + export (#21)

Backlog round 6, 2026-09-18. Issue: [#21](https://github.com/ChaosChild/fragmt/issues/21) (rung-5 remainder; rungs 1–4 + the references core and pane shipped in v0.9.0). Locked by Lavish review same day (`.lavish/okf-graph-export.html`): **D1** export = the graph formats **plus a bundle zip** — the operator's one divergence from the recommendation; the lossy-snapshot tradeoff (no history) is accepted, viz.html stays out. **D2** the graph view is a full main-pane state beside Doc / Resolution. **D3** rendering is a hand-rolled SVG force layout — zero dependencies, hash-seeded positions, ~300-node ceiling with a deterministic ring fallback. **D5** export surfaces = graph-view toolbar buttons + the `fragmt export` CLI. The whole round is a pure read of the bundle: the graph is derived fresh from **body links** on every call (the `references`/`referenced-by` frontmatter cache is never trusted — adopted-but-unfixed repos may not have it), and nothing here writes a byte into the docs. Branch `feat/okf-graph-export`.

## What ships

- **`deriveGraph`** (new `src/core/graph.ts`): the repo-wide read the view and every export share — `{ nodes: { path, title, type, status?, tier, stale }[], edges: { from, to }[] }`. The `docPaths` enumeration, `extractRefs` for edges (the exact semantics the frontmatter fields derive from: both §6.1 forms, broken links skipped, fenced-code and self-link exclusion), `trustTier`/`isStale` for node encoding. Concepts only: reserved files excluded as sources and targets (the §3.1 rule the derived fields follow). Isolated docs stay in as nodes. Unreadable docs are skipped (validate's story, not this walk's). Deterministic ordering: nodes by path, edges by (from, to).
- **Renderers** (same module, pure functions over the graph): `graphToMermaid` (`flowchart LR`, stable `n0…nN` ids, JSON-quoted display titles with escaped quotes/backslashes, a header comment carrying the date and counts), `graphToDot` (`digraph`, `rankdir=LR`, quoted paths as node ids, titles as labels), `graphToJson` (`{ generated, nodes, edges }`). Escaping is shared and round-trip tested — titles are free text under OKF's open vocabulary.
- **Bundle zip** (new `src/core/zip.ts`): a minimal dependency-free ZIP writer — store method (no compression), UTF-8 names, fixed DOS timestamps so bytes are deterministic and testable. `bundleZip(repoRoot, docsRoot)` walks the docsRoot **working tree** (the share-what's-on-disk snapshot D1 picked), skipping `.git` directories, every entry resolved and contained under docsRoot. No zip reading exists anywhere in the codebase.
- **CLI**: `fragmt export [--format mermaid|dot|json] [--out <file>]` — JSON is the default format (agents first); `--out` writes the file, otherwise stdout. `fragmt export --bundle [--out <file>]` produces the zip (default name `<bundle-dir-name>.zip` beside the working directory). Non-OKF repo: exit 2 + the `init --okf` hint (the `validate` convention). Non-OKF is the only gate — export reads `main`'s working tree like every other read surface.
- **Server**: `GET /api/graph` — JSON nodes+edges; `?format=mermaid|dot` returns text with the matching content type (`text/plain; charset=utf-8` for mermaid, `text/vnd.graphviz` for dot). `GET /api/export/bundle` — the zip as an `application/zip` download. Non-OKF repos: `{ okf: false }` from `/api/graph` (the `/api/validate` convention) and a 404 `{ okf: false }` from the bundle route (no payload exists to send). Routes sit with the other reads, param-free scans.
- **Graph view** (new `ui/src/GraphView.tsx`): the fourth main-pane state beside Doc / Resolution (the `ResolutionView` wiring precedent). Entry: an icon button in the sidebar header, rendered only when `/api/meta` says `okf: true` (the banner's flag). Force simulation in a rAF loop with capped iterations and settle detection; initial positions seeded from path hashes so the same repo state renders the same shape twice. Above ~300 nodes: a deterministic ring layout instead, with a quiet note in the view. Node = circle, fill by trust tier (unverified steel / machine-confirmed accent / human-reviewed green — the badge semantics, quiet by default); stale adds a dashed warn ring; isolated docs render dashed-outline in steel. Hover highlights the node's edges and shows the tooltip (title, path, type, tier, link count); click navigates the main pane to the doc **through the guarded navigation queue** (the search palette's open-in-main entry — the dirty-guard matrix gains this case in the harness). Wheel zooms, background drag pans, Fit / − / + controls. Toolbar: "N docs · M links" and the export set per D5 — Copy Mermaid, download .dot, .json, and Bundle .zip. Plain CSS from the existing token set.
- **Harness additions**: GraphView mounts from a fixture payload; node click runs the guarded queue; the sidebar entry button is absent when `okf` is false.

## Pipeline

1. **Core graph** — `src/core/graph.ts`: types, `deriveGraph(repoRoot, docsRoot)` (mirror the read-only half of `recomputeGraph`; the graph map before any splice), the three renderers.
2. **Core zip** — `src/core/zip.ts`: `zipEntries(entries: { name, data }[])` → `Uint8Array` (local headers, central directory, EOCD; CRC-32 table); `bundleZip` composing the contained walk with it.
3. **CLI** — `src/cli/index.ts`: the `export` command in parseArgs + usage + dispatch; `--bundle`, `--format`, `--out`; OKF gate with exit 2.
4. **Server** — `src/server/index.ts`: the two routes; `ui/src/api.ts` gains typed `fetchGraph` (+ the bundle URL used by the download button).
5. **UI** — `GraphView.tsx`, the sidebar-header entry in `Sidebar.tsx`, the pane-state wiring in `App.tsx` (enter/leave per the ResolutionView pattern), `styles.css` additions from the token set.
6. **Tests** — see below. **Docs** — README OKF section extended (graph view, export formats, bundle zip); BACKLOG graduation rides the merge; #21 closes against the round PR.

## Excluded

- viz.html and any static HTML graph page — locked out (not in the spec; re-voted 2026-09-18). The bundle zip is files-as-files, not a renderer.
- Attested Computation (§10) — stays out; the locked revisit comes due after this round completes the initial build (next discussion, not this one).
- Graph editing — the view is a lens; links are edited in bodies where they are canonical.
- Zip compression (store method only), incremental graph caching, layout persistence, non-OKF graph surfaces, `log.md` auto-maintenance.

## Tests (~30)

`tests/okf-graph.test.ts`: deriveGraph parity (edges ≡ the frontmatter fields after a save), reserved exclusion both directions, broken-link skip, isolated docs present, unreadable-doc skip, deterministic ordering; renderer shapes + escaping (title with quotes/backslashes/brackets through Mermaid and DOT), stable id assignment. `tests/okf-zip.test.ts`: zip structure (signature, central directory walk, entry names round-trip through an independent reader pass), deterministic bytes across calls, `.git` skip, containment (a docsRoot path can never escape into an entry name). `tests/server-graph.test.ts`: JSON shape, `?format=` content types, `{okf:false}` / 404 gating, freshness (edit a body link → response changes with no commit). `tests/okf-export-cli.test.ts` (tmp-repo e2e): stdout bytes per format, `--out` writes the file, `--bundle` produces a readable zip of the working tree, exit 2 + hint in a non-OKF repo. UI harness: mount from fixture, guarded click, entry gating.
